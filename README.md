# Cin-Track
CinéTrack est une application web permettant aux utilisateurs de découvrir et de consulter un catalogue de films et de séries à partir des données récupérées via une API MockAPI.

L'application offre plusieurs fonctionnalités, notamment l'affichage dynamique des films et séries sous forme de cards, la recherche par titre, le filtrage par type, la pagination et l'affichage des détails dans une fenêtre modale.

Les utilisateurs peuvent également ajouter des films et des séries à leurs favoris, les consulter dans une sidebar et les retrouver après l'actualisation de la page grâce à LocalStorage.

Le projet est développé avec HTML, Tailwind CSS et JavaScript, en utilisant Fetch API, Async/Await, les modules ES6 et les méthodes modernes de manipulation des tableaux (map, filter, find et reduce).

Objectif : développer une application dynamique, interactive et bien structurée, tout en mettant en pratique les concepts fondamentaux de JavaScript et la gestion des données provenant d'une API.
